Security note: unlike the mobile app (which stores your key in the OS Keychain/Keystore), this web wallet keeps your recovery phrase in this browser's localStorage. Setting a PIN (Settings tab, after creating/restoring a wallet) encrypts it at rest with a key derived from that PIN (PBKDF2 + AES-GCM, via the browser's own Web Crypto API) -- real protection against someone reading localStorage directly, but it only holds up if your PIN itself isn't guessable, and offers no protection once the wallet is unlocked in an open tab. Best used for testnet or small amounts; the mobile app is the safer choice for real funds. See README.md for the full reasoning.
