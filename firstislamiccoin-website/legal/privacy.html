1. The short version

This is a static informational website. It does not require an account, does not have a login, and does not run analytics or third-party trackers. There is nothing to opt out of because nothing is being collected beyond what any web server sees by default (below).

2. What we collect

Standard web server request logs — IP address, requested page, timestamp, user agent — kept only as long as needed to operate and secure the hosting infrastructure, then discarded. Nothing else. No cookies are set by this Site, and no third-party analytics, advertising, or tracking script is loaded.

3. What we don't do

  • We don't ask for your name, email, or any identifying information to browse this Site.
  • We don't sell, rent, or share any data, because we don't collect any beyond the request logs above.
  • We have never seen, and cannot see, any wallet's private keys, recovery phrase, or balance — this Site contains no wallet software.

4. Third-party links

This Site links to open-source repositories and documentation. Once GitHub, Cloudflare, or other third-party services are actively used to host this Site or its linked source code, their own privacy practices apply to your interaction with them, not to us.

5. Changes to this policy

As real products (wallets, a staking service, an explorer) launch, this policy will be replaced with one that accurately describes what they collect — not before. Material changes will update the "Last updated" date above.
