Roadmap

Where things actually stand

No dates below — this project doesn't publish launch-date promises it can't guarantee. What it does publish is status, kept current as work lands.

Phase 0 — Discovery and brand kit Done

Audited the codebase this project forks from, and built the FirstIslamicCoin brand kit: logo, palette, typography, icon sets.

Phase 1 — Core node rebrand and chain parameters Done

Rebranded the node, set FIC's own chain parameters, converted the premine into a true spendable genesis output, replaced the coin-age reward with the fixed 10 FIC model, and removed the developer donation. Verified with a full unit and functional test pass.

Phase 2 — Testnet validation In progress

A multi-node public testnet is live and staking now: reward and block-spacing correctness are being checked block by block, alongside stress testing (high transaction volume, reindexing, reorg handling) and the functional test suite.

Phase 3 — Desktop wallets, CI and release pipeline Built, not deployed

A release CI workflow for macOS, Windows and Linux installers is written and now confirmed running for real: a test run built genuine Linux (tarball + .deb) and Windows (NSIS installer) artifacts successfully on GitHub's own runners. macOS still doesn't build (a runner-availability gap, not a code problem). No release has actually been tagged or published yet, and none of this is code-signed — no certificates exist for that.

Phase 4 — ElectrumX light-wallet backend Live

Rebranded with FIC's real genesis hashes and address parameters, then verified with actual block and transaction indexing against a live node — not just a daemon connection. Two servers now deployed and confirmed answering the real Electrum protocol at testnet-electrum1.firstislamiccoin.com:51001 and testnet-electrum2.firstislamiccoin.com:51011 (TCP; add 1 for the TLS port on each).

Phase 5 — Mobile wallets (Android + iOS) Built, not deployed

A single Flutter codebase rebuilt with FIC's chain parameters, its wrapped-token swap screen removed, and English/Arabic localization wired up. Two real crypto bugs (an address-decoding test fixture typo, and a genuine testnet key-derivation bug where testnet keys didn't actually differ from mainnet ones) were found and fixed. An unsigned debug build of the Android app now exists and is downloadable for testnet testing — see Wallets — but that's not the same as an app-store release: still not yet built for either real app store, no signing keys or store accounts yet, and the Android toolchain itself needed a real fix (Gradle/AGP were years out of date) before any build was even possible.

Phase 6 — Staking service Live

A custodial staking gateway verified end-to-end against a real node — signup, deposit, an on-chain staking reward credited at the right amount, referral payouts — now deployed and reachable at staking-api.testnet.firstislamiccoin.com. Non-custodial ("cold") staking still needs a consensus feature this project doesn't have yet; see Staking.

Phase 7 — Web wallet Live

A no-install browser wallet talking to the same gateway the mobile app uses, tested live against a real node — the same testing caught a real fee-calculation bug, fixed in both wallets. Now deployed at wallet.firstislamiccoin.com.

Phase 8 — Block explorer Live

Public search over blocks, transactions and addresses, plus FIC's exact supply math, verified endpoint by endpoint against a live testnet node. Now deployed at explorer.firstislamiccoin.com.

Phase 9 — Website In progress

This site, deployed and live at firstislamiccoin.com. Arabic and Urdu localization and a downloads page wired to real releases are still ahead.

Phase 10 — Mainnet launch In progress

A full security review is done — real CVEs fixed, CI gaps closed, sanitizer and static-analysis test jobs wired in and verified genuinely passing — plus a launch runbook and operations guide. Still ahead: the genesis key ceremony and mainnet launch itself, which only follow a solid testnet track record.
